# Nexa premium AI support website

## Scope
- Replace the placeholder with a single, cinematic product-story homepage for Nexa.
- Follow the supplied neutral palette, large typography, floating navigation, and restrained violet accents.
- Build detailed original product interfaces for the hero, unified inbox, AI agent, knowledge base, workflow builder, integrations, and messenger.
- Generate a cohesive set of editorial industry and testimonial imagery rather than using stock photography.
- Add polished Framer Motion sequences, scroll-linked transitions, parallax circles, counters, marquee, typing states, and responsive mobile compositions.

## Build approach
1. Establish the color, type, spacing, radius, shadow, and motion tokens in the global design system.
2. Add reusable primitives for reveal motion, organic background graphics, product-window framing, and animated counters.
3. Compose the homepage as one continuous sequence with varied editorial layouts and full-scale product scenes.
4. Generate and integrate five art-directed images for industries and the testimonial.
5. Add mobile navigation, reduced-motion behavior, horizontal workflow/product exploration, and precise metadata.
6. Verify the full page at desktop and mobile sizes, including interaction, animation, overflow, and visual balance.

## Technical details
- TanStack Start route at `/` with React 19 and Tailwind CSS v4.
- Motion for React for timeline, scroll progress, in-view, spring, and marquee animation.
- Lucide icons for functional interface symbols; custom CSS geometry for orbital and organic graphics.
- All styling uses semantic tokens; no backend or account logic is included.
