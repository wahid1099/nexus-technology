# Conversation Catalyst

Create a premium AI customer-support SaaS website with a visual direction strongly inspired by the current Chattrn website's visual storytelling, animation quality, product presentation, spacing, and editorial layout.

IMPORTANT:
Do not create a generic SaaS landing page.
Do not use generic gradient hero sections.
Do not use repetitive 3-column feature cards.
Do not make every section look like a dashboard card.

The website should feel like a carefully art-directed product website with large typography, sophisticated motion, product screenshots, floating UI elements, organic shapes, and cinematic scrolling.

Create an ORIGINAL brand called:

Nexa

Tagline:

Turn Every Conversation Into Revenue

"Hero + 3 cards + feature grid + pricing cards + FAQ"

A visual product story.

Organic graphics.

Product screenshots.

Image transitions.

Minimal copy.

Strong visual rhythm.

Every section should have one clear visual focus.

The final result should feel like a premium SaaS company that invested heavily in design and motion.

Make the visual quality comparable to a polished modern startup website, while keeping the branding and assets completely original.
